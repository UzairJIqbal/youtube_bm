YouTube Study Bookmarks

Save the moments that matter in long YouTube lectures, courses and tutorials without pausing to type.

Download the latest release View the source on GitHub

  • Alt+B bookmarks the current moment, titled from the video's chapter.
  • Alt+C twice saves a clip you can loop until it sinks in.
  • Markers on the progress bar, notes and #tags, and a library to search everything you've saved.
  • Export to Markdown for Obsidian, Notion or Logseq, with clickable timestamps.

Private by design

Your bookmarks stay in your browser. No account, no tracking, no server.
